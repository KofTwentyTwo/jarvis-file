# Praesidium2 -- Reference Implementation

This is the project that started it all. Praesidium2's interactive design document site was the original single-tenant implementation that Jarvis File was extracted from.

**Live site:** https://praesidium2-design.web.app

## What This Example Shows

- Full `jarvis-file.config.js` with real structure (credentials sanitized)
- 4 document types: Executive Summary, System Design, Implementation Plan, Business Review
- 7-person team directory with 2 AI agents (Jarvis + F.R.I.D.A.Y.)
- Custom welcome flow with role-based routing
- Cross-document link map for chat auto-linking
