# Templates

Guide to customizing and creating new document templates.

## Available Starter Templates

| Template | File | Purpose |
|----------|------|---------|
| Executive Summary | `index.html` | C-suite one-pager with hero, stats grid |
| System Design | `system-design.html` | Tabbed technical architecture |
| Implementation Plan | `implementation.html` | Phased build plan with task cards |
| Business Review | `business-review.html` | Findings table, recommendations |
| Presentation | `presentation.html` | Slide deck with keyboard navigation |

## Creating a New Template

Every template follows the same HTML skeleton. Include the config loader and auth gate in `<head>`, and the framework scripts before `</body>`.
