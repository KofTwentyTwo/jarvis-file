# Design System

CSS component guide for Jarvis File's dark-theme design system.

## CSS Custom Properties

Theme colors are set dynamically from `window.JF.theme` by `config-loader.js`. Override by changing config values.

## Available Components

| Component | Class | Description |
|-----------|-------|-------------|
| Card | `.jf-card` | Dark surface with border, radius, padding |
| Stat Card | `.jf-stat-card` | Number + label for KPIs |
| Stat Grid | `.jf-stat-grid` | Responsive grid for stat cards |
| Badge | `.jf-badge` | Small colored label |
| Table | `.jf-table` | Striped dark table with hover |
| Code Block | `.jf-code` | Monospace with syntax background |
| Tabs | `.jf-tabs` | Horizontal tab navigation |
| Section | `.jf-section` | Content section with margin |
| Hero | `.jf-hero` | Full-width gradient section |
| Grid | `.jf-grid-2/3/4` | Responsive column grids |
| Alert | `.jf-alert` | Callout boxes (warn, info) |
| List | `.jf-list` | Styled list with markers |
| Divider | `.jf-divider` | Horizontal rule |
